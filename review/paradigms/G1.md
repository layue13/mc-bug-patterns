# G1 无视领地 / 权限 / 禁用方块
规则：`mc-g1-world-edit-without-protection-check`、`mc-g1-unbounded-explosion-power`

## 判定目标
玩家可触发的世界修改是否绕过了保护插件挂载的统一检查点。

## 必须读的代码
命中方法全文 + 调用它的入口（`useOn`/`mineBlock`/`onItemUse`/机器 `tick`/`onBlockStartBreak`）+ 触发者是不是玩家。

## 确认条件
1. 触发者能追溯到**玩家行为**（物品使用、玩家放置的机器、玩家投掷物）。
2. 调用链上从入口到 `setBlock/destroyBlock/removeBlock` 之间**没有** `mayInteract`、`BlockEvent.BreakEvent`/`EntityPlaceEvent`、`ForgeHooks.onBlockBreakEvent`、`FakePlayer`+保护检查、`canPlayerEdit` 中的任何一个（也检查它们是否在被调用的**其他方法**里——规则只看同一方法）。
3. 爆炸：威力来自玩家可放大的量（数量/能量/配置未限制），且无上限 clamp。

## 排除条件
- 仅 `isClientSide` 分支或只操作自己生成的临时方块。
- 机器由世界生成/非玩家触发（如自然生长树），且不是玩家可控。
- 检查在调用者里（跨方法）——引用该行。

## 需要人工
保护检查依赖外部插件 API 约定（无法在仓库内确认）。

## 建议修法
所有改世界的路径先走 `mayInteract` 或发 `BreakEvent`；FakePlayer 绑定真实所有者；爆炸威力 `Math.min(power, config.maxPower)`。

## 对应站点案例
采矿机(131)、约束之镐(115)、洛基之戒(157)、建筑之杖(169)、神龙反应堆(129)、毁灭新星(152)。
